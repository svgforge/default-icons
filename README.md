# Default Icons

A collection of icon sets, sorted into category folders.

These icons serve as a base for tests and the [WordPress Plugin Icon Library](https://github.com/svgforge/icon-library).

## Build

The build script [build.sh](build.sh) uses [svgforge-cli](https://github.com/svgforge/svgforge-cli) to generate a symbol sprite (`OUT/symbol/sprite.svg`) from the individual SVG files and starts a local web server to preview the result.

```sh
./build.sh
```
